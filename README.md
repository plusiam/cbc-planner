# CBC Planner — 개념 기반 프로젝트 설계 웹학습지

개념 기반 프로젝트 설계안(0~3단계)을 브라우저에서 바로 작성하는 웹학습지입니다.
**단일교과용**과 **융합교과용** 두 서식을 한 페이지에서 전환하며, 입력 내용은 서식별로 따로 자동 저장됩니다.

🔗 https://plusiam.github.io/cbc-planner/

## 기능

- 단일교과 / 융합교과 서식 전환 (상단 버튼)
- 단계 탭(0 표지 · 1 교육과정 분석 · 2 평가 계획 · 3 학습 계획 · 탈고 점검)과 탭별 진행률, 「전체 보기 / 단계별 보기」 전환, 이전·다음 이동
- 자동 저장 (브라우저 localStorage) · 행 추가·이동·삭제 · 탐구 목록 카드 추가
- 칸마다 「ⓘ 작성 안내」 접기/펼치기, 툴바에서 한꺼번에 펼치기/접기
- 「🔎 참조 보기」 — 성취기준·핵심 아이디어·단원명 등 앞 단계에서 정한 것을 읽기 전용 패널로
- 준거(S) 개수와 평가 기준표 행 수 대조 배지
- 탈고 전 점검표 체크박스와 진행률
- 내보내기
  - 텍스트(마크다운) 복사 / .md 저장 — 노트북LM·AI 챗봇에 붙여넣어 점검받기
  - HTML 파일 저장 · 인쇄/PDF 저장 (안내문 제외, 어느 보기에서든 전체 출력)
  - 작업 파일(.json) 저장·불러오기 — 다른 컴퓨터에서 이어 쓰기, 설계안 수합
  - 빈 양식 인쇄 (안내문 포함 A4)
- AI와 함께 쓰기 — 「AI에게 서식 알려주기」로 안내문을 복사해 채팅에 붙이고, 받은 JSON을 「AI 답변 붙여넣기로 불러오기」에 넣기 (아래 절)

## 파일 구성

- `index.html` — 화면·스타일·툴바·단계 내비게이션
- `schema-single.js` — 단일교과용 서식(칸·안내문·점검표)
- `schema-fusion.js` — 융합교과용 서식
- `app.js` — 렌더링·자동 저장·단계 이동·내보내기 엔진, 계획 API(`window.cbcPlanner`)
- `schema-flat.js` — 서식을 AI가 읽기 좋은 구조로 평탄화 (브라우저·Node 공용)
- `build-schema.js` → `schema.json` — 공개 스키마. `node build-schema.js`로 생성

서식 문구나 칸을 고칠 때는 `schema-*.js`만 수정하면 됩니다. 칸의 `key`를 바꾸면 기존 저장 데이터와 어긋나므로 유지하세요. 서식을 고친 뒤에는 `node build-schema.js`를 한 번 실행해 `schema.json`을 다시 만듭니다.

## AI와 함께 쓰기

Claude·ChatGPT·Gemini·NotebookLM 어디에서든 대화로 짠 설계안을 이 웹학습지로 가져올 수 있습니다.

1. 📥 내보내기 > **🤖 AI에게 서식 알려주기** — 안내문이 클립보드에 복사됩니다. 채팅창에 붙여넣고 그 아래에 학년·교과·성취기준·단원 아이디어를 적어 대화합니다.
2. AI가 마지막에 내놓는 JSON 코드 블록을 복사합니다.
3. 📥 내보내기 > **📋 AI 답변 붙여넣기로 불러오기**에 붙여넣습니다. 서식에 없는 칸은 건너뛰고 몇 건인지 보여 줍니다.

안내문에는 학생 실명·명단·연락처를 어떤 칸에도 넣지 말라는 지시가 들어 있습니다. 채팅에 붙이는 자료에도 학생 식별 정보를 섞지 마세요.

AI가 서식의 작성 규칙까지 읽게 하려면 `https://plusiam.github.io/cbc-planner/schema.json`을 함께 주면 됩니다. 안내문에 이미 링크가 들어 있고, 링크를 못 여는 AI에는 파일로 첨부하면 됩니다.

## 서식 출처

`개념 기반 프로젝트 설계안 템플릿` 단일교과용·융합교과용 (2026-09-01 개정) — 2단계를 수행과제와 그 밖의 평가 증거로 분리, 평가 기준표를 분석적·과제형 루브릭으로 정리.
